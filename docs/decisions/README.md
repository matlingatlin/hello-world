# Architecture Decision Records (ADRs)

One file per significant decision, so we can always see *why* the system is the way
it is.

## How to use
1. Copy `0000-adr-template.md` to `NNNN-short-title.md` (next number in sequence).
2. Fill it in. Set **Status** to Proposed, then Accepted once agreed.
3. If a later decision reverses it, set the old one to Superseded and link the new one.

Decisions are not made silently in code — they land here first.
