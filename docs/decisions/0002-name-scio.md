# 0002. Name & brand: Scio

- **Status:** Accepted (working name — pending formal trademark + domain clearance)
- **Date:** 2026-08-07
- **Phase:** 1 (brand)

## Context
The product needs a name. Two earlier candidates were screened and rejected on collisions:
Keel (a London startup in almost our exact category — no-code/low-code dev platform with
engineering best practices — plus keel.sh, a Kubernetes tool) and Mason (crowded: a YC
smart-device company, a Swedish AI-SQL startup, and mason.nvim; generic word, hard domain).
We wanted a distinctive, ownable name aligned with the core thesis: a builder that
understands your intent better than the alternatives.

## Decision
- Name: **Scio** — Latin for "I know" (from *scire*, to know). It maps directly to the
  thesis: the system that understands. Short, clean, distinctive.
- Treated as the working name until a formal trademark and domain check clears it.

## Consequences
- Brand voice can lean on "knowing / understanding" without being literal.
- The visual identity (ADR-0003) is deliberately name-agnostic, so it holds regardless.
- Action before hard-locking: trademark screen + domain acquisition.

## Alternatives considered
- Keel — rejected: direct same-category competitor collision + keel.sh.
- Mason — rejected: crowded in software, generic, hard domain.
- Truss, Cairn — considered; set aside in favour of Scio's meaning fit.
