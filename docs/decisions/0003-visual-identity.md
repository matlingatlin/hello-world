# 0003. Visual identity: drafting-table direction

- **Status:** Accepted
- **Date:** 2026-08-07
- **Phase:** 1 (brand)

## Context
Scio needs an identity that signals "developer-grade, for people building for real" and
avoids the current generic AI-app look. Three AI-default looks to avoid: warm cream +
high-contrast serif + terracotta; near-black + a single acid-green/vermilion accent;
broadsheet hairlines with zero radius and dense columns.

## Decision
- Direction: **drafting table / blueprint** — quiet, precise, engineered; the app should
  feel like the code it produces.
- Palette, typography, radius/spacing, and components: see docs/DESIGN.md (exact tokens).
- Signature: a restrained construction-line / coordinate motif on surfaces, plus the
  product's own numbered-annotation tiles used as the brand mark.
- Light default; dark as a first-class toggle.

## Consequences
- Monospace (IBM Plex Mono) is used as a brand signal (labels, version hashes, "your code")
  for engineering credibility.
- The signature is the product's own mechanic, not decoration.
- Light default welcomes non-technical founders; dark serves the dev-leaning.
- Name-agnostic: survives the (still-working) name decision.

## Alternatives considered
- The three AI-default looks above — rejected as defaults rather than choices for this brief.
